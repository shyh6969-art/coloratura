# קולורטורה

פרויקט שממיר ציור למוזיקה — לא באמצעות טבלת המרה שרירותית ("צהוב = דו"), אלא דרך מנוע שמחלץ תכונות חזותיות אמיתיות (צבע, קו, קומפוזיציה), מתרגם אותן דרך שכבת תיווך רגשית מבוססת-מחקר, ומרכיב מהן תקציר מוזיקלי שמוזן למנוע הרמוניה פרוצדורלי עם ניהול-קולות אמיתי בארבעה קולות (SATB).

השם עצמו כבר גשר בין שני התחומים: "קולורטורה", במקור הלטיני, פירושו "צביעה" — ובעולם הזמרה האופראית זה הכינוי לקישוט מלודי מפואר.

## הצינור

```
ציור (JPG)
  │
  ├─ feature_extraction.py    חילוץ תכונות CV: בהירות, רוויה, טמפרטורת צבע, עובי/עקמומיות/
  │                           צפיפות קו, סימטריה, שטח שלילי, מוקד ניגודיות, כיוון תנועה
  │
  ├─ semantic_features.py     ציוני CLIP (zero-shot) לערכיות/עוררות/מתח וסיווג סגנון —
  │                           השכבה שתופסת תוכן רגשי שסטטיסטיקת פיקסלים עיוורת אליו
  │                           (למשל שמיים בוערים מול פיורד שחור אצל מונק)
  │
  ├─ mapping_engine.py        ממזג את שתי השכבות למרחב תיווך: ערכיות, עוררות, מתח-פורמלי
  │                           (ניגוד צבע/גיאומטריה) ומתח-רגשי (איום/רזולוציה) — שני צירי
  │                           מתח נפרדים, לא אחד, אחרי שהתברר שהם עונים על שאלות שונות.
  │                           הפלט: "תקציר מוזיקלי" — אובייקט JSON עם סולם, מודוס, טמפו,
  │                           מטר, צורה, תזמור, ארטיקולציה, עקומת דינמיקה ורזולוציה הרמונית
  │
  ├─ composer.py               גרסת "lite": התקציר → MIDI עם פרוגרסיה קבועה (בסיס להשוואה)
  │
  ├─ stage_a.py                הגרסה המלאה: דקדוק הרמוני פונקציוני (Markov משוקלל מעל
  │                            טוניקה/סאב-דומיננטה/דומיננטה) + ניהול-קולות אילוצי בארבעה
  │                            קולות — תנועה מינימלית, בלי מקבילים של חמישית/אוקטבה, רזולוציית
  │                            קדנצה מודעת-מודוס, מטר אמיתי (7/8 = 2+2+3), צורת ABA/דרך-מולחן
  │
  ├─ synth.py                  MIDI → WAV: סינתיסייזר אדיטיבי עצמאי (בלי SoundFont/בינארי
  │                            חיצוני) עם פרופיל הרמוניות ומעטפת ADSR לכל משפחת כלי-GM
  │
  └─ stage_b.py                 (אופציונלי, דורש מפתח API) שולח את ה-WAV של דרגה A
                               ל-Suno (דרך sunoapi.org) כ"cover" reference + prompt
                               טקסטואלי שנבנה מהתקציר, ומקבל בחזרה רינדור AI ריאליסטי
```

## הרצה

```bash
pip install -r requirements.txt
python src/run_test.py      # מריץ על 5 ציורי הבדיקה ב-test_images/, כותב ל-output/
python src/render_wav.py    # ממיר את כל קובצי ה-MIDI שנוצרו ל-WAV
```

### דרגה B (אופציונלי, בתשלום)

דורש מפתח API מ-[sunoapi.org](https://sunoapi.org). חשוב: ל-Suno אין מנגנון "בצע את התווים האלה בדיוק" — ה-`cover` endpoint מקבל **URL** לקובץ אודיו קיים (לא MIDI) כהשראה, ומייצר סאונד חדש בהתאם לפרומפט טקסטואלי שנבנה מהתקציר. זו פרשנות מחדש של ה-AI, לא ביצוע נאמן של ניהול-הקולות מדרגה A.

```bash
export SUNO_API_KEY=sk-...          # (Windows: $env:SUNO_API_KEY="sk-...")
python src/run_stage_b.py           # כל 5 הציורים — עולה כסף, כ-2-3 דקות לציור
python src/run_stage_b.py munch_the_scream   # ציור בודד
```

הקובץ המקורי (רינדור דרגה A) שמשמש כ-reference חייב להיות בכתובת ציבורית — הוא כבר מתארח ב-`assets/stage_a_wav/` בריפו הזה, ונקרא דרך raw.githubusercontent.com.

`output/` (לא נשמר בגיט, נוצר מחדש בכל הרצה):
- `*.json` — התקציר המלא לכל ציור
- `report.txt` — טבלת השוואה + פירוט מלא לכל ציור
- `midi/lite/`, `midi/stage_a/` — קובצי MIDI
- `wav/lite/`, `wav/stage_a/` — קובצי WAV

## ציורי הבדיקה

חמישה ציורים ציבוריים (public domain, Wikimedia Commons) שנבחרו קיצוניים מבחינה סגנונית: ואן גוך (ליל כוכבים), קנדינסקי (קומפוזיציה 8), מונדריאן (קומפוזיציה II), מונה (נימפיאות), מונק (הצעקה) — כדי לבחון האם המיפוי מבחין ביניהם בצורה שמרגישה נכונה למי שמכיר את שתי השפות.

## ממצא מרכזי מהבדיקה

הרצה ראשונית עם VAT (ערכיות/עוררות/מתח) חד-ממדי נתנה תוצאה הפוכה: מונדריאן קיבל ציון "מתח" גבוה יותר ממונק. הסיבה — מדד מבוסס-פיקסלים קרא ניגוד צבעים, לא איום. הרשת של מונדריאן צורמת לעין אך רגועה לגמרי מבחינה רגשית; אצל מונק זה הפוך. זה מה שהוביל לפיצול "מתח" לשני צירים נפרדים (`tension_formal` ו-`tension_emotional`) שמזינים יעדים הרמוניים שונים.

## מה עדיין חסר / מפושט

- שכבת היצירה מרנדרת רק כיוון אחד (ציור ← מוזיקה). הכיוון ההפוך (מוזיקה ← ציור) לא הותחל.
- הבס תמיד בפוזיציית-יסוד (בלי היפוכים); רק קול הסופרן מקבל תווי-מעבר/שכנים מלודיים.
- הסינתיסייזר העצמי (`synth.py`) פשוט (אדיטיבי, לא SoundFont) — לא נשמע כמו תזמורת אמיתית.
- `stage_b.py` עובד קצה-לקצה מול ה-API החי (נבדק בפועל על "הצעקה" של מונק — ג'נרציה מלאה, MP3 תקין הורד בהצלחה). זו עדיין פרשנות-מחדש של Suno על בסיס reference audio + prompt, לא ביצוע נאמן של ניהול-הקולות מדרגה A — ראו הערה בראש `stage_b.py`.
- סיווג הסגנון וקטגוריות הפונקציה ההרמונית (T/S/D) הם הקונבנציה של מוזיקה מערבית קלאסית; לא הותאמו למסורות מוזיקליות אחרות.
